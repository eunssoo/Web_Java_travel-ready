# TravelReady

여행 계획을 등록하고 여행별 준비물 체크리스트를 관리하는 웹 프로젝트입니다.

## 프로젝트 목표

JSP, Servlet, JDBC를 활용하여 MVC와 Front Controller 구조를
직접 구현하고 웹 요청 처리 흐름을 이해합니다.

## 주요 기능

- 회원가입 및 로그인
- 여행 등록, 조회, 수정, 삭제
- 여행 유형별 기본 체크리스트 제공
- 준비물 추가, 삭제 및 완료 상태 관리
- 준비물 진행 상황 확인

## 사용 기술

- Java
- JSP / Servlet
- JDBC
- Oracle Database
